
  # Premium Personal Portfolio Website

  This is a code bundle for Premium Personal Portfolio Website. The original project is available at https://www.figma.com/design/Iiz7TZpcxLGHN2R8HaEmpn/Premium-Personal-Portfolio-Website.

  ## Running the code

  Run `npm i` to install the dependencies.

  Run `npm run dev` to start the development server.

  ## Ask Me chat setup

  The Ask Me chat uses OpenRouter through a server-only Next.js API route. Copy
  `.env.example` to `.env.local`, then add the OpenRouter key to
  `OPENROUTER_API_KEY`. Never place that key in a `NEXT_PUBLIC_` variable.

  `OPENROUTER_MODEL` defaults to `openai/gpt-5.4-mini`. Set
  `NEXT_PUBLIC_SITE_URL` to the deployed site URL and keep
  `NEXT_PUBLIC_SITE_NAME` as the portfolio name used for OpenRouter requests.
